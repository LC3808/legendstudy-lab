# Social sign-in marks

These small, local assets keep the login buttons independent of third-party runtime requests.

- `google-g.png` — official multicolor Google G, from the asset linked in [Google Identity branding guidelines](https://developers.google.com/identity/branding-guidelines).
- `kakao-login-symbol.png` — the black login speech bubble cropped from Kakao's official Korean medium/narrow button PNG at `https://developers.kakao.com/tool/resource/static/img/button/login/full/ko/kakao_login_medium_narrow.png`. The #FEE500 source background is retained so it blends into the official Kakao button color.
- `apple-sign-in-symbol.png` — white Apple mark cropped from the black button example in [Apple Design Resources](https://developer.apple.com/design/resources/images/thumbnails/Thumbnail-Tech-SIWA-Buttons_2x.png). The black source background blends into the black button.

Provider artwork has not been recolored or redrawn.
