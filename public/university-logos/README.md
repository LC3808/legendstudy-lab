# Official university identity assets

These files identify universities in the existing public university catalog. They
are original files from university-owned websites, not AI-generated illustrations
or a representation of sponsorship. Source URLs, verified date and SHA-256 are in
`src/data/university-logos.json`. Inline Ewha SVG is extracted verbatim from its
university-owned header. No recoloring, distortion, cropping or evaluation inference.
White-only variants use a contrasting presentation surface. Original aspect ratios
are maintained using object-fit:contain; desktop56px/mobile48px logo slots.

41 of42 universities have retrieved/visually checked assets. Sogang remains a named
monogram fallback: the main/admissions sites did not return a retrievable usable logo
in this session; no unofficial substitute was used. This does not affect its catalog,
priority, source links or evaluation state. Replace only from a verified official
source and update the provenance manifest. Retain the universities' trademark rights.
