## 배포와 검증

시험·문항, 공식 근거, 공개 범위와 원복 SQL은 c61e0dc에 기록했다. 1차 배포 후 실제 일반 계정에서 ‘문항 입력 유형을 확인 중’이 지속되는 결함을 발견했다. Registry 기반 편집기가 참조하는 입력 유형 목록에 두 문항을 추가했다. 수정 커밋 b81539c, 최종 운영 배포 935b653e-ed64-4481-9846-63cf80cb8667. 자동 검사 22건과 WEB 빌드 통과 후 일반 사용자 검증을 다시 수행했다.
