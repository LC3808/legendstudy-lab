# LegendStudy+ 수능 LAB·내신 LAB 향후 기능 및 구독 BM 로드맵

작성일: 2026-11-11
상태: **Owner 아이디어·장기 기획 기록 / 세부 가격·한도·법적 검토 미확정 / 구현·운영 변경 승인 아님**
현재 Codex 자동채점·등급컷 작업과 별개의 후속 로드맵. 기존 논술 LAB 및 앱의 학습 기록과 연결하되 현재 작업 범위를 임의 확대하지 않는다.

## 1. 수능 LAB — 오답노트와 취약 영역 분석 (유료 핵심 기능)

### 무료 기반
- 최근 5개년 평가원 모의평가·수능 자동채점 이후 **원점수·등급·시험/과목별 결과**를 개인 학습 기록에 저장.
- 서버 DB에는 사용자별 채점 결과와 문항별 정오 정보를 저장하여 본인 기록 조회 및 허용된 범위의 집계 분석에 활용.
- **채점 및 점수·등급 확인은 무료**로 유지.

### 오답노트
- '나의 학습 → 오답노트'에서 여러 시험의 틀린 문항을 한곳에 모아 확인.
- 시험·연도·과목·단원·유형 필터, 문제/정답/해설 열람, 다시 풀기 및 학습 상태(미학습·복습·완료) 기록.
- 문항/해설 원본 접근 권한과 표시 정책은 기존 자료 제공 정책과 정합성 검토.
- 문항별 정오·단원/유형 태그를 기반으로 데이터가 누적되면 **취약 영역 분석** 및 보완 학습 제안 제공. 표본이 적을 때 과도한 진단 금지.

### 유료화 초안
- 무료 이용자: 오답노트 **3~5문항**까지 저장·열람 가능(정확한 한도 추후 결정).
- 유료 구독자: 상향/확장된 오답 저장, 복습 및 취약 영역 분석.
- 무료 채점 결과와 기존 기록은 구독 종료 후에도 유지. 구독 만료 시 기존 오답 삭제 대신 열람·추가·분석 권한 정책을 별도 설계.
- 구독 상품별 저장 개수, 분석 횟수, 복습 기능 차등 및 가격은 별도 확정.

## 2. 내신 LAB — 학교 시험지 업로드 기반 AI 변형문제

### 학생 가치
- 학생이 학교 내신 시험지를 업로드 → 시험/문항 추출·분석 → 유사 유형의 **새로운 변형문제**와 해설 생성.
- 학교·학년·학기·과목·시험 종류(중간/기말) 메타데이터와 원본/파생문항 연결.
- 무료 AI 생성 **약 3회** 가설, 구독 상품별 **5회·10회 등** 사용량 차등(기간·과목·문항 수 단위는 미확정).
- 원본 시험지가 없는 학생도 '우리 학교 시험 기출 변형문제 보기'에서 확보된 자료를 기반으로 변형문제를 이용; 유료 구독 중심.
- 동일 시험지 중복 업로드 탐지, OCR/문항 구조화 품질검수, 원본과 생성 문제의 차이·정답 검증 필요.

### 시험지 수집 Growth Loop
시험지 업로드 → 검수·중복 확인 → 변형문제 제공 + 포인트 적립 → 자료 축적 → 같은 학교 학생의 검색·변형문제 이용 → 추가 업로드·구독.

### 포인트·결제 아이디어
- 유효한 시험지 업로드에 포인트 지급(검수 완료 후 지급, 중복·허위·저품질 제외).
- 포인트를 앱 내 유료 기능과 구독 결제에 활용하는 구상.
- **중요 미결정:** 포인트의 현금성/환급성, 사용처, 소멸, 부정 적립, 회계·세무, 앱스토어/플레이스토어 인앱결제 및 구독 결제 규정 적합성. 특히 **스토어 구독료를 자체 포인트로 직접 대체 결제할 수 있다고 전제하지 않는다.** 플랫폼별 적법한 리워드/할인/이용권 설계를 검토한 후 확정.
- 시험지의 업로드 권한, 저작권·재배포 허용 범위, 학교·교사 자료 포함 여부를 검토. **업로드 동의가 곧 서비스 전체 공개·재판매 허락을 뜻하지 않음.** 권한 불명 자료는 비공개 검수/접근 제한, 필요 시 허락 기반 자료 또는 원본 비공개 파생문제 제공 모델 검토.

### B2B 확장
- 학원과 제휴하여 학교별 기출·유형 분석·변형문제 패키지 제공.
- 학생용 구독과 학원용 라이선스/좌석제/문항 생성 크레딧을 별도 설계.
- 제휴 기관 자료 권한·재사용 범위와 품질 검수 체계 마련.

## 3. 내신 LAB — 수행평가 준비하기

- '수행평가 준비하기' 메뉴: 교과(국어·사회·수학 등), 과제 주제, 채점 기준(루브릭), 분량/조건, 학생 답안(글쓰기 또는 수리 풀이) 입력.
- 기존 **논술 LAB의 평가·피드백 엔진과 UI 패턴 재사용**하되 교과·과제 유형별 평가 스키마와 수학 풀이 검증을 분리.
- 학생 답안에 대해 **채점 기준별 강점·보완점·수정 제안**, 다시 작성·재평가 제공.
- 사용자가 원하면 **모범답안/예시 풀이** 열람. 학생의 학습을 돕는 예시로 명시하고 실제 학교 교사의 확정 채점/정답처럼 제시하지 않음.
- 구독 상품별 월/기간 평가 횟수 차등. 정확한 횟수·가격·재평가 소모 규칙 추후 결정.
- AI 채점은 교사 평가를 대체하는 공식 성적이 아님을 UI에서 구분.

## 4. 공통 구독·데이터 아키텍처 (후속 설계 과제)
- 수능 LAB 오답/취약 분석, 내신 LAB 변형문제, 수행평가 피드백의 **통합 구독 vs 기능별 요금제** 비교.
- 무료 한도와 구독 한도는 서버에서 권한·사용량을 원자적으로 집행; 재시도/실패 환급·재생성·무료체험·결제 복원 설계.
- 기존 논술 LAB의 첨삭권/크레딧 정책을 임의 변경하거나 구독에 자동 통합하지 않음.
- 원본 시험지/채점 결과/생성 문항/피드백/학습 분석을 별도 데이터로 저장하고 생성 버전·출처·검증 상태 추적.
- 이용자별 성적과 학교 정보의 접근 통제, 집계 데이터의 목적 적합성, 미성년 이용자 보호 및 공개 범위 점검.
- AI 생성 비용(페이지당 추출, 문항당 생성, 피드백 토큰)과 실제 결제 전환을 파일럿으로 검증.

## 5. 제안 단계 및 미확정 사항
1. **Phase A 수능 LAB:** 무료 자동채점·등급 저장 안정화 → 문항별 정오 데이터/해설 매핑 → 무료 3~5개 오답노트 → 유료 무제한/상향 + 취약 분석.
2. **Phase B 내신 LAB 파일럿:** 시험지 업로드·비공개 검수·변형문제 생성 → 무료 3회 가설/유료 5·10회 가설 → 학교별 검색.
3. **Phase C 리워드/B2B:** 자료 이용 권한·품질 확보 후 포인트 실험, 플랫폼 결제 규정 검토, 학원 제휴.
4. **Phase D 수행평가:** 논술 LAB 엔진 기반 루브릭 평가·재작성·모범답안, 구독 횟수 차등.

**Owner 확정 전 미결정:** 오답 무료 3 vs 5개, 무료 변형문제 3회의 기간, 구독 등급/가격/횟수, 포인트 가치·구독 결제 가능 여부, 시험지 공개 정책, 대학/학교 데이터 제공 범위, B2B 라이선스.

## 6. 현재 실행 제한
본 문서는 **향후 기능 기록**이다. Codex의 2026-11-11 자동채점·등급컷 작업에 새 범위를 추가하지 않는다. DB·RPC·앱·WEB·결제·스토어·포인트 시스템 변경 또는 배포를 승인하지 않는다. 추후 Owner와 제품·비용·권리·결제 정책을 확정한 후 단계별 구현 지시서를 작성한다.
