## P0. APP 학습 기능 통합 — 우선 착수
목표: WEB에서 구현된 학습시간·학교별 공부 순위·친구 초대를 Flutter Native UI로 연결하고 WEB/APP 동일 Supabase Backend 사용. WebView 대체 금지, 별도 집계 엔진 금지.

### 화면/정보구조 제안
1. 기존 APP '학습' 탭을 **학습 홈**으로 확장: 상단 오늘 공부시간·누적 공부시간·진행 중 타이머, 중앙 시작/일시정지/종료, 아래 최근 학습기록·주간 요약, '우리 학교 공부 순위' 카드/진입 버튼.
2. '우리 학교 공부 순위' 전용 Flutter 화면: 기본 탭 **참여 학생 수 Top 학교**, 기본 기간 **전체 기간**; 총공부시간/1인당 평균/참여 학생 수 3탭; 기간 전체/이번 주/지난주/최근 30일; TOP10 + 우리 학교 주변 순위; 본인 학교 강조; 다른 학교 가입·참여 학생 수는 서버 null → '**'; 총시간·평균은 기록자 3명 이상 공개.
3. 학교 미등록 상태: 기존 학교 선택 UI 재사용, 학교 등록 CTA; 등록 후 학교 카드 및 랭킹 노출.
4. 친구 초대: 학습 홈 및 학교 순위 화면에서 OS 네이티브 공유, 링크 복사; WEB 초대 RPC 및 랜딩 재사용. 앱 링크 수신은 플랫폼별 딥링크 설정/지원 상태 검증 후 구현. **앱 미설치→설치 후 토큰 복원은 아직 미구현이며 지원 가능성 확인 전 완료 주장 금지.**
5. 마이페이지: 학교 설정·공부 기록·학교별 순위 진입을 기존 네비게이션과 일관되게 연결. 학습 기능을 관리자 전용으로 제한하지 않음.
