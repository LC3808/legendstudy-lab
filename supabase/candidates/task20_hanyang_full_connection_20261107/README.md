# 한양대 자연 전체 운영 연결 승인 후보 · 2026-11-07

상태: **TECHNICAL_READY / 운영 적용 승인 대기**. 실제 첨삭 품질은 Owner·사용자 검증 대상이다. 이 후보는 운영에 적용하지 않았다.

## 승인 대상

기존 공개 4시험·8문항 보존. 추가 **17시험·34문항** 연결 후 총 **21시험·42문항**을 제공한다. 추가 범위는 남은 15시험·30문항, 준비된 2024 모의 1시험·2문항, 누락 확인된 2024 수시 자연 오후1 1시험·2문항이다. 기존 16시험·32문항 ID는 유지하며 오후1만 충돌 검사 후 준비한 고정 ID로 등록한다.

정확한 시험·문항·Math leaf ID는 `release-manifest.json`, PDF 해시·문항 페이지는 `web-pdf-additions.json`이다. 전체 86시험을 공개하는 변경이 아니다.

## 검증된 범위

- 격리 TEST: 17시험·34문항 Catalog, 공식 채점 기준 214행, 공식 풀이 요약 102단계, 원본 지면 133쪽 연결.
- 각 문항의 문제·출제 의도·채점 기준·풀이를 공식 PDF SHA-256와 실제 페이지에 고정. 텍스트 추출의 수학 기호 손실은 추측하여 교정하지 않고 공통 Worker에 공식 원본 PNG를 함께 전달한다. 요약에 없는 상세 배점·풀이도 원본 기준이다.
- 공통 Worker의 전체 입력 크기 최대 1,727,272 bytes로 기존 2 MiB 응답 한도 이내. 평가 근거 pin 누락 시 원본 전달 거부.
- 공개 함수 적용/원복 SQL을 TEST 트랜잭션에서 실행하고 최종 롤백. 정의·ACL 복원 확인. `test-results.json`, `rollback-test.json` 참조.
- 문제 전용 PDF 17개는 인증된 TEST Storage 읽기와 SHA 대조 완료. 공식 해설 이미지 테이블은 학생 직접 조회 금지.
- 신규 Provider 호출·TEST 이용권 지급·운영 데이터 변경 **0건**. 새로운 실제 평가 생성·첨삭 품질 검증을 의미하지 않는다.

## 적용 범위와 순서 (Owner 승인 후)

1. 운영 프로젝트 `stlhijzpjfgwwdgunlsd` 재확인. 네 함수 정의·ACL, 기존 4시험·8문항 공개 상태, 현재 Pages/Worker 배포 ID와 비밀값 제외 설정을 백업한다. SQL의 사전 함수 해시가 다르면 적용 중단.
2. `hide-new-exam.sql`: 신규 오후1 ID를 Catalog 제외 목록에 먼저 추가하여 자료 staging 중 이름이 조기 노출되지 않도록 한다. 기존 목록은 그대로다.
3. `packages.sql`: 기존 Registry ID를 검사하고 오후1만 중복 없이 등록. 34개 공통 Math Package 연결. 기존 평가·답안·History·이용권 테이블은 갱신하지 않는다.
4. `private-source-schema.sql`: 비공개 원본 전달 테이블을 준비한다. 로컬 보관 `source-rows`를 `compile_source_rows.py`로 변환하여 정확한 34개 검수 해시만 연결한다. TEST 일괄 SQL을 운영에 적용하지 않는다. 원본 이미지·키는 Git에 넣지 않는다.
5. `web-pdf-additions.json`의 문제 전용 PDF 17개만 비공개 `essay-material-originals` Storage에 저장한다. 기존 동일 해시는 덮어쓰지 않는다. 업로드 후 크기·SHA를 대조하고 두 `*-policy.sql`로 해당 문제 PDF만 일반 로그인 사용자에게 허용한다. 공식 채점표·풀이 PNG는 공개하지 않는다.
6. `open.sql`: 정확한 34 Math leaf만 admission/release Catalog에 추가, 15개 기존 비공개 시험의 Catalog 제한을 해제하고 오후1도 노출. 공통 `math_evaluation` claim에 해시 검증된 공식 지면 전달을 연결한다. 기존 finalize·경희 Q3 검수 경로·RPC ACL은 보존한다.
7. WEB에 준비한 세 데이터 파일을 배포하고 `scope-additions.json`의 정확한 시험·문항 ID를 기존 Pages 및 Essay Worker 공개 설정에 **추가**한다. 기존 Secret이나 다른 대학 scope를 교체하지 않는다. 별도 평가 Worker를 만들지 않는다.
8. 일반 로그인 사용자로 Catalog/PDF/답안 작성·첨삭 요청 가능 상태를 확인한다. 기존 4시험·8문항 및 다른 대학 공개 상태와 비교한다. Provider 호출·실제 이용권 차감은 하지 않는다. 결과·History·무료 재첨삭은 기존 공통 계약을 유지한다.

## 원복

1. 신규 17시험·34 leaf의 설정 추가분만 제거해 신규 첨삭 진입을 닫는다. 기존 4시험·8문항과 다른 대학 scope는 유지한다.
2. 직전 WEB/Worker 배포·설정을 복원한다. 암호화 Secret을 가려진 값으로 재저장하지 않는다.
3. `rollback.sql`의 적용 후 함수 해시가 일치하는지 확인하고 실행한다. 기존 admission, release_catalog, math_evaluation을 복원한다. Catalog는 신규 오후1을 비공개로 유지한 기존 정의로 돌아간다. 두 신규 PDF 읽기 정책만 제거한다.
4. 신규 Registry·Package·원본 및 이미 생성된 평가·History는 삭제하지 않는다. 이용권·결제·환불 원장은 변경하지 않는다. 이후 다른 작업이 함수를 변경했다면 원복을 강행하지 않고 변경분만 분리한다.

## 승인 요청

위 **17시험·34문항에 한정한 운영 Registry/Package·비공개 Storage·공통 Worker 입력·Catalog/권한·WEB/Worker 공개 설정 연결**을 승인 요청한다. 승인 전 신규 운영 공개·배포는 실행하지 않는다. 한양대 완료 후 다음 대학은 별도 승인 대상이다.
