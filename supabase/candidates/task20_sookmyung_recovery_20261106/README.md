# TASK20 숙명여대 과거 자료 복구 — 운영 승인 검토 후보

기준: 2026-11-06 KST. **운영 미적용 / 공개·평가 비활성.**

## 정확한 변경 범위

원본 PDF 102개(102개 SHA-256, 764쪽)를 대조했다. 문제 PDF 40개는 38개 시험에 해당한다. 2025·2026 모의 인문1/2는 별도 회차가 아니라 문항 파일이므로 합친다.

- 기존 8시험·22문항의 ID와 저장 상태를 보존한다.
- 미등록 30시험·70상위문항만 기존 `essay_exams`, `essay_questions`에 검수 대기 상태로 추가하는 후보다.
- 학년도 2021~2026의 미등록 범위. 2027 및 2026 수시 기존 등록을 재생성하지 않는다.
- 2021 자연계는 원문의 1-1(a/b)~1-3(a/b)를 하나의 상위 문항 아래 유지한다. 신규 시험의 상위 문항 수는 파일 개수로 정하지 않는다.
- `registration-plan.json`에 시험명, 기존 스키마의 결정적 UUID, 문항 ID, 원본 해시를 모두 수록했다.
- 새 테이블/권한/함수/Provider/이용권/History/결제 변경 없음.
- PDF 업로드·문항별 평가 근거 매핑·검수 승인·Package 생성·공개 범위 확대는 이 SQL에 포함되지 않는다. 따라서 등록만으로 첨삭 가능 상태가 되지 않는다.

## 파일과 적용 순서

1. `registration-plan.json`과 기존 Registry를 다시 대조한다.
2. Owner가 위 범위를 승인한 후 `register-review-only.sql`을 적용한다.
3. 30/70 증가, 기존 8/22 동일, 신규 공개 0건, 평가 정책 변화 없음 확인.
4. 다음 단계에서 원본 페이지 매핑·공식 평가 기준 검수를 진행한다. 공개 활성화는 별도 승인 범위다.

## 중복 방지 및 원복

등록은 트랜잭션 및 메타데이터 테이블 잠금을 사용한다. 같은 ID의 재실행은 동일 상태만 허용하고, 다른 ID로 같은 연도·유형·계열·회차가 존재하면 중단한다. 운영 적용 직전에는 계열 별칭까지 포함한 사전 대조를 다시 수행해야 한다.

`rollback-review-only.sql`은 이번 후보 ID만 대상으로 한다. 기존 행, 예상 밖 추가 문항, 변경된 상태, 평가·답안·검수·History 등의 외래키 참조가 발견되면 자동 삭제를 거부한다. CASCADE 삭제를 사용하지 않는다. 참조가 생긴 이후 원복은 별도 검토가 필요하다.

## 검증 구분

`local-test-result.json`: 실제 운영 DB가 아닌 임시 로컬 PostgreSQL 17, 기존 APP canonical migration을 이용한 검증이다. 원본 PDF의 모든 수식·평가기준 정밀 검수 PASS나 운영 복구 PASS를 뜻하지 않는다.

재현 도구: `scripts/essay-materials/task20_prepare_sookmyung.py`, `task20_test_registration.py`. 사전 Registry 스냅샷과 PDF 추출 본문은 비공개 로컬 입력으로 받으며 Git에 원문을 저장하지 않는다.
