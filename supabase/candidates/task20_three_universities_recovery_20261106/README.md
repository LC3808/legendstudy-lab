- 한양대 2024 자연 오후1: 현재 수집 원본에서 문제지 미확인. 해설·합격자 답안으로 문제를 임의 생성하지 않는다.

## 적용·원복

1. 승인 후 현재 Registry와 후보 ID 및 연도·계열·회차를 재대조한다. 기존 데이터 드리프트가 있으면 중단한다.
2. `register-review-only.sql` 실행: 트랜잭션·테이블 잠금, ID/상태 충돌 및 같은 시험 다른 ID 검사. ‘자연’/‘자연계열’ 별칭도 중복 방지한다.
3. 신규 56/146 비공개, 기존 66/146 해시 동일, 새 runtime policy/Math set 0 확인.
4. `rollback-review-only.sql`: 이번 후보 ID만 대상. 상태 변경·예상 밖 문항·학습/검수 등 외래키 참조가 있으면 삭제 거부. CASCADE 사용 안 함.

## 검증

`local-test-result.json`: 임시 PostgreSQL 17에 canonical migration과 기존 Registry 66/146를 재현했다. 중복 실행, 기존 행 보존, RLS 보존, 일반 사용자 쓰기 차단, 상태 변경 원복 거부, CASCADE 참조 원복 거부, 정상 원복을 통과했다. 운영 적용 및 실제 평가 PASS가 아니다.

재현: `task20_prepare_three_universities.py`, `task20_test_registration.py`. 원본 전문은 비공개 입력으로만 사용한다.
