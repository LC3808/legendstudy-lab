## 공식 근거 매핑의 현재 수준

`new86-package-source-audit.json`에 시험·문항별 원본 해시, 후보 페이지, 문항 번호 관찰 여부, 공식 채점 기준/출제 의도/예시답안 제목 위치를 기록했다. 후보 페이지는 정밀 매핑 완료를 뜻하지 않는다. 다른 문항 번호가 같은 페이지에 있는 경우를 구분했다. 195문항은 후보 페이지 중 PDF 전용 글리프가 있어 원본 수식 이미지 대조가 필요하다. 이 수치는 OCR 정확도나 195개 수식의 오류 판정이 아니다.

검수 완료 0 / 미완료 216. 가상의 기준·Package를 만들거나 검수 상태를 승격하지 않았다. 기존 숙명여대 2026 자연 2시험의 6개 채점 기준 분리는 별도 기존 시험 작업이며, 신규86 완료 수에 합산하지 않는다.
